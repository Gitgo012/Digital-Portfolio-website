# Yash Kuletha — Data Portfolio

A responsive, static portfolio highlighting my early-career work in data engineering,
data science, analytics, and applied AI. It includes internship experience, selected
projects, role-specific resumes, and a compact embed for my RAG-powered personal
assistant at [meet-yash.vercel.app](https://meet-yash.vercel.app/).

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

The contact form uses EmailJS. The personal assistant is hosted separately and can
also be opened directly if its host does not allow embedding.
